# 武蔵ドリル (musashi-drill)

教習所の学科対策ソフト「武蔵」の学習体験（1問1答 → 確定 → 即座に正誤と解説）を、
**資格を問わず使い回せる暗記エンジン**にしたもの。

- 電車の往復のような、短く区切られた固定セットで周回する
- 「迷った」ボタンで、正誤とは別に自己申告の不確実さを記録する
- 1〜2周は全問刷り込み、3周目からは誤答・迷った問題だけの重点復習モードに自動で切り替わる
- サーバ不要・ログイン不要・完全オフラインで動く PWA（ホーム画面に追加して使う）

## なぜ作ったか

既存の暗記/クイズOSSは「サーバに繋いだ状態で1回だけ解く」ものか、
「覚えた問題を出さなくなる」SRS（間隔反復）が主軸のものが大半で、
**電車の中で毎回同じセットを固定時間で周回する**という使い方に噛み合うものが無かった。
このリポジトリは、その隙間だけを埋める。

## 使い方（今すぐ試す場合）

```bash
npm install
npm run dev       # data/ 配下のYAMLをJSONへ変換してから開発サーバ起動
npm run build     # 本番ビルド（Service Worker込み）
npm run preview   # ビルド結果をローカルで確認
```

ビルドした `dist/` を、Cloudflare Pages や GitHub Pages 等の静的ホスティングに置くだけで動く。
バックエンドは無い（Phase 1でSupabase等による進捗同期をオプションとして足す予定）。

**スマホでは、ブラウザで開いた後に必ず「ホーム画面に追加」すること。**
通常のタブのままだとiOS Safariの仕様で保存した進捗が消えることがある
（ホーム画面に追加したPWAはこの対象外）。念のため、ホーム画面の「進捗を書き出す」で
定期的にバックアップも取れる。

## データについて（重要）

`data/<資格ID>/` 配下のYAMLが問題データ本体。**過去問そのものは、多くの場合、
試験実施団体や出版社の著作物**であり、このリポジトリのMITライセンスの対象外。

- このリポジトリには実際の過去問データを含めない（`.gitignore` 対象）。
- 自分用に使う場合は、`data/` 配下に自分でYAMLを追加する（後述のスキーマに従う）。
  私的使用の範囲であれば著作権法上問題になりにくいが、**そのリポジトリをpublicにしない**こと。
- 同梱しているのは `_sample/` の自作サンプル問題のみ（著作権フリー、動作確認・スキーマ理解用）。

## 問題データのスキーマ

```yaml
# data/<資格ID>/meta.yaml
id: some-qualification
title: 資格名
subjects:
  - { id: subject-a, title: 科目A, exam_questions: 12, pass_threshold: 8 }
session:
  set_size: 50       # 1セットの上限問題数
  time_limit_min: 30
phases:
  brute_force_laps: 2    # 何周までは全問モードか
  graduate_streak: 3     # 迷わず正解が何連続で「卒業」扱いになるか
```

```yaml
# data/<資格ID>/<科目>.yaml
- id: subject-a-0001
  subject: subject-a
  topic: このトピック名
  variants:                     # 実際に出題された文言のみを追加する。AIによる新規生成は禁止
    - { source: "2024-06", text: "問題文…" }
  choices: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"]
  answer: 0                     # 0-indexed
  explanation: |
    解説本文。断定できない条文番号などは「(条文要確認)」と明記する。
  law_refs: ["根拠条文など"]
  figure: null                  # 図が必要な問題は今のところ非対応
```

新しい資格を追加するときは `data/` に新しいディレクトリを作るだけでよい。
アプリ本体のコードは変更不要（資格名をハードコードしていない）。

## 設計上の決定（抜粋）

- **SRSを主軸にしない**：覚えた問題を出さなくなる方式は、セット時間が読めなくなり継続を壊す。
  代わりに「全問固定周回 → 誤答/迷った問題だけの重点モード」という2段階にした。
- **「迷った」は正誤と独立の軸**：まぐれ正解を捕まえるための自己申告フラグ。
- **オフラインファースト**：IndexedDBが常に正。サーバへの同期は「あとで追いつく」だけの
  オプション（Phase 1で追加予定）であり、無くてもアプリは完全に動く。
- **右利き・片手・親指操作**：選択肢は縦積み、確定・迷ったボタンは画面下部固定。
